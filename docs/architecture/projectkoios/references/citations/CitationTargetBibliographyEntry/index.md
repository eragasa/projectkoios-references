# `CitationTargetBibliographyEntry`

One source-ordered target bibliography entry with exact locator/content identity and an optional non-fabricated References observation ID.

This public class is implemented and validated in the owning module; it introduces no rights, review, manuscript-use, ingestion, scientific, or publication authority.
