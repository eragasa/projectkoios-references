# `CitationTargetOccurrence`

One ordered literal-key occurrence supplied by the target owner, including direct/generated origin and optional bibliography/todo indexes.

This public class is implemented and validated in the owning module; it introduces no rights, review, manuscript-use, ingestion, scientific, or publication authority.

Evidence: [module implementation](../implementation.md) and [`test__CitationDocumentTargetAdapter.py`](../../../../../../tests/test__CitationDocumentTargetAdapter.py).
