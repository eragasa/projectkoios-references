# `CitationDocumentProjectionRequest`

Frozen complete runtime intent binding the target snapshot, aligned
bibliography observations, replayed identity projection, document observations,
an optional exact replay-valid availability evaluation Result, and exact
replay-validated link results rather than bare links. Only observations equal
to that Result's derived tuple can carry negative authority.

This public class is implemented and validated in the owning module; it introduces no rights, review, manuscript-use, ingestion, scientific, or publication authority.

Evidence: [module implementation](../implementation.md) and [`test__CitationDocumentProjection.py`](../../../../../../tests/test__CitationDocumentProjection.py).
