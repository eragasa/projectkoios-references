# `CitationSourceDocumentObservation`

Bounded positive, inaccessible, or incomplete document evidence for one
literal key in one target snapshot. A `coverage_status=complete` value is not
independent absence authority; `not-observed` additionally requires the exact
replay-valid availability evaluation Result that derived the observation.

This public class is implemented and validated in the owning module; it introduces no rights, review, manuscript-use, ingestion, scientific, or publication authority.

Evidence: [module implementation](../implementation.md) and [`test__CitationDocumentProjection.py`](../../../../../../tests/test__CitationDocumentProjection.py).
