# `CitationSourceDocumentLinkResult`

Frozen result binding one exact link request and semantic linker identity to its
neutral link. Validation replays the sole focused link builder and requires
exact output equality.

This public class is implemented and validated in the owning module; it introduces no rights, review, manuscript-use, ingestion, scientific, or publication authority.
