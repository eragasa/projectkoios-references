# `CitationBibliographyMembershipStatus`

Closed target-bibliography membership outcomes: `defined`, `undefined`, and the
reserved `not-evaluated`. Membership remains separate from accepted/candidate
identity resolution and from document availability.

This public class introduces no rights, review, manuscript-use, ingestion,
scientific, or publication authority.

Evidence: [module implementation](../implementation.md) and
[`test__CitationDocumentProjection.py`](../../../../../../tests/test__CitationDocumentProjection.py).
