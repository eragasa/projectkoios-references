# `ReferenceEvidenceTranscript`

Immutable clean-transcript evidence, including generation, lineage, text
identity, processor identity, configuration, and warning count.

## VVUQ classification

Its tests are `software_verification`; no numerical verification, scientific
validation, or uncertainty quantification is established.

## Software-verification evidence

`tests/test__IngestionEvidence.py` verifies transcript contract, generation,
status, layout lineage, text digest, and byte-length requirements.
