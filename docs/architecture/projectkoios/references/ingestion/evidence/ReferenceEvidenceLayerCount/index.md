# `ReferenceEvidenceLayerCount`

Immutable named count used by the derivation audit to declare coverage of an
ingestion evidence layer.

## VVUQ classification

Its tests are `software_verification`; other VVUQ evidence classes do not
apply.

## Software-verification evidence

`tests/test__IngestionEvidence.py` verifies bounded layer decoding and required
audit coverage counts.
