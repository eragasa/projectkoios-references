# courses.authority.selected_bibliography

## Ownership

References owns the deterministic scope-selected private bibliography handoff. It filters an existing exact render only through Courses-supplied opaque predecessor locators and never through citekeys.

## Coordination

Courses supplies a revised manifest identity and ordered predecessor selection envelope. References verifies the current predecessor queue, retained candidates, rendered entries, observations, and accepted projections, then emits exact private bytes plus path-free provenance.
