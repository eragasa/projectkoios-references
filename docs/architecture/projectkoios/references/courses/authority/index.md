# courses.authority

## Ownership

References owns immutable requests, actionizers, results, queue projection, append-only identity/asset decisions, idempotent replay, receipts, and Search/Courses authority projections.

## Coordination

The module receives Courses evidence and owner runtime capabilities, persists only through schema-5 CAS, and returns safe path-free results to API and Search.
