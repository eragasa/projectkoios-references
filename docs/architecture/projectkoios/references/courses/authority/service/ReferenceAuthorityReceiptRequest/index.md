# `ReferenceAuthorityReceiptRequest`

## Responsibility

Request a post-append owner reread receipt.

## Boundary

`ReferenceAuthorityReceiptRequest` is owned by `projectkoios.references.courses.authority.service`. It does not grant scientific, publication, rights, or cross-owner authority beyond its typed contract.

## Collaboration

The contract collaborates only through immutable typed values and the `DataObjectActionRequest` taxonomy boundary. Private filesystem paths, catalog locations, and protected payload bytes are excluded from public results.
