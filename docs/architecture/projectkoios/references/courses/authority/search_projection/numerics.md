# courses.authority.search_projection: numerics

This capability performs no scientific numerical analysis. Counts, bounds, byte lengths, and SHA-256 identities are software-integrity values rather than scientific measurements. Persisted projections are limited to 10,000,000 bytes, 10,000 bindings per projection, 10,000 Ingestion links per binding, and 100,000 authority evidence IDs per binding. The reader verifies exact expected length and SHA-256 before UTF-8 or JSON decoding.
