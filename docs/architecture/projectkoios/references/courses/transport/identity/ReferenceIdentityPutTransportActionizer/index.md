# `ReferenceIdentityPutTransportActionizer`

## Responsibility

Adapt primitive transport input to one atomic identity PUT.

## Boundary

`ReferenceIdentityPutTransportActionizer` is owned by `projectkoios.references.courses.transport.identity` and follows the single-action `DataObjectActionizer` taxonomy. It carries no filesystem path, database location, source bytes, or mutable container.

## Collaboration

It collaborates only with the matching typed owner action and immutable transport values. API may route or serialize the result but need not traverse the private authority graph.
