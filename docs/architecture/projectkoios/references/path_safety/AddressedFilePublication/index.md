# `AddressedFilePublication`

Immutable result of descriptor-confined content-addressed stream publication:
reporting path, SHA-256 digest, byte size, and whether no-replace publication
created a new file or verified an existing one.

It grants no rights, use, ingestion, review, Search, scientific, bibliographic,
or publication authority.

Evidence: [path-safety implementation](../implementation.md) and [document/reference operation tests](../../../../../../tests/test__DocumentReferenceOperations.py).
