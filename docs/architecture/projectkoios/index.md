# `projectkoios` namespace package

This repository owns only the `references` child in the shared `projectkoios`
Python namespace. Sibling packages and system architecture remain outside this
component's authority.

## Documented child

- [`projectkoios.references`](references/index.md)

The namespace has no local `__init__.py`; setuptools discovers the owned child
as a namespace package.
