# Technical-debt tasks

These records capture concrete maintainability, verification, and contract
limitations in `projectkoios-references`. They do not change repository
ownership, authorize cross-repository work, or weaken fail-closed authority,
rights, and publication boundaries.

Each backlog records an explicit status for completed, partial, and proposed
work. A task may be completed incrementally, but compatibility-sensitive
identity or persistence changes require an explicit migration rather than
silent reinterpretation.

## Backlogs
