# Padberg--Hoffmann citation-graph seed

This graph contains the 34 bibliography edges transcribed from
`padbergHoffmann2015`. Candidate identifiers are local discovery identities;
proposed citekeys do not become canonical until metadata review.

`nodes.csv` deliberately supports an optional abstract. Six DOI-backed records
were checked against Crossref during the pilot, but Crossref supplied no
abstract for them. Empty abstract fields are therefore explicit missing data,
not failed transcription.

The graph records direct edges only. It does not recursively import each
candidate's bibliography or treat citation as endorsement or claim support.
